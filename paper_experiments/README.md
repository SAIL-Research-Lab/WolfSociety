# Full-LLM manuscript experiments

This is the active experiment package. `legacy_experiments/` contains the old
hybrid runtime, exploratory studies, and the numerical results associated with
the previous manuscript. No old result is evidence for this implementation.
Every actor in the new main society, including harmful accounts, takes its
action through the LLM policy. Deterministic market mechanics remain an
environment. Explicit rule and Watts controls are labeled separately.

## Experiment map

| Family | Manuscript purpose | Main configurations |
|---|---|---|
| `p01` | Primary scaling, transition width, harmful count, threshold sensitivity | S1; N=100,200,300,500,1000,2000; 12 independent main seeds |
| `p02` | Fixed-count dilution and depth/social decomposition | K=0,1,3,5,8,12; all sizes; q=0,.5,1 plus no-social contrasts |
| `p02b` | Appendix response prediction near larger harmful counts | K=0,2,4,8,16,32,64, K/N≤.32; all sizes |
| `p03` | Cross-scenario scope and continuous harm | S1–S4; N=300,1000 |
| `p04` | Coupling interventions | Baseline, weak/strong feedback, conformity, reach, attention, deliberation, no feedback, no multihop |
| `p05` | Information mechanisms | Private only, content only, proof only, full, attention, private precision, sender-return annotation off, shuffled identity, delay, hub placement |
| `p06` | Role homogeneity and diversity | Mixed, risk averse, value, trend, social, aggressive; explicit rule reference; clean mixed population at every N |
| `p07` | Backbone robustness | N=100,1000; run this family separately against each pinned local model |
| `p09` | Liquidity-depth scaling | q=0,.5,1; all sizes |
| `p10` | Controller robustness replacing old quota audit | Full LLM, half LLM, all rule; all sizes; use `--seeds 1-6` for original six-seed allocation |
| `p11` | Watts threshold null | Matched size/grid; Beta(2,8), preferential attachment degree≈8; explicitly no LLM |
| `language` | New language-content necessity comparison | Full text, numeric sentiment, neutral text at matched exposure budgets |
| `controller_factorial` | New attack/receiver attribution | Benign LLM/rule × harmful LLM/rule |

P08 defense exploration is not part of the final manuscript and is excluded.
The original numerical QRE precision is represented by a deliberation prompt
contrast, not equated with LLM sampling temperature. Original fixed LLM quotas
are replaced by explicit controller contrasts. Existing text and tables must be
rewritten after observing the new experiments. A role instruction is an
experimental manipulation, not proof that its intended behavior occurred; use
the behavior/information diagnostics and traces to check the manipulation.

`no_feedback` freezes the market observation presented to the policy. This is
an observation intervention and does not establish that market dynamics are
causally unnecessary. `sender_return_annotation_off` removes the sender-return
annotation repeated in inbox items. The same public return remains in market
history, and the LLM can still infer credibility from it. This annotation
ablation does not implement the old rule controller's frozen trust-learning
state and must not be described as disabling trust or reputation learning.
`language` changes received content while preserving the corresponding delivery
process within each intervention. Agent reactions can subsequently diverge,
so equal initial budgets do not imply equal realized conversation histories.

## Server workflow

Install the project and start the vLLM endpoint using the server instructions in
the repository documentation. The runner uses its OpenAI-compatible endpoint;
the local development computer does not need a GPU or vLLM installed.

From the repository root:

```bash
python -m pip install -e '.[dev]'
export PYTHONPATH="$PWD/src:$PWD"
export VLLM_BASE_URL=http://127.0.0.1:8000/v1
export VLLM_API_KEY=EMPTY
```

Start with a tiny explicit QA run. These outputs are marked mock and cannot
freeze a scientific main grid:

```bash
python -m paper_experiments.runner plan --mock --stage smoke --families all \
  --sizes 20 --seeds 9001 --horizon 3 --manifest runs/qa/manifest.json
python -m paper_experiments.runner run --manifest runs/qa/manifest.json --output runs/qa
```

Run a throughput/behavior pilot using a real served model. Substitute the
server's model name and the exact weights revision or local content hash.
The scripts create a manifest and print the number of generations by default;
`EXECUTE=1` also executes it. Model outputs are never generated by `plan`.

```bash
EXECUTE=1 scripts/run_pilot.sh SERVED_MODEL WEIGHTS_REVISION runs/pilot-small \
  --families p01 --sizes 20,50,100 --seeds 1001 --horizon 5
```

Set model-specific chat options explicitly when needed. For a supported
thinking-model template, append `--chat-template-kwargs '{"enable_thinking":false}'`
to disable hidden reasoning during action generation. The value must be a JSON
object and is preserved in the manifest and backend provenance. Determine
`--max-tokens` and these template options in the pilot: the default 512 output
tokens may be insufficient if the model spends its allowance on reasoning or
long structured actions. These settings must remain fixed for the main sweep.

After validating policy coverage, language decisions, budget enforcement,
baseline trading, malformed-output rates and measured token throughput, pilot
the intended full horizon and all required society sizes:

```bash
EXECUTE=1 scripts/run_pilot.sh SERVED_MODEL WEIGHTS_REVISION runs/pilot \
  --families all --sizes 100,200,300,500,1000,2000 --seeds 1001-1003
```

The final runner line gives `run_dir=.../real/<manifest-hash>`. Use that exact
directory in analysis and grid commands. Broad pilot candidates are
α=0,.01,.03,.06,.10,.20,.40; no hybrid threshold is assumed.

The script defaults to P01 at N=100,300. The explicit **all-family** pilot above
is a substantial batch: 3,363 episodes and about **58.28 million LLM decisions**
with three seeds and 30 rounds, before refinement. At the same grids, twelve
main seeds would require about 233 million decisions. Select families and
measure actual token throughput before allocating this complete workload.
The broad protocol is supplied for completeness, not as a throughput claim.

```bash
python -m paper_experiments.analysis runs/pilot/real/RUN_HASH --output runs/pilot-tables
python -m paper_experiments.grids refine runs/pilot/real/RUN_HASH --output runs/refined-grid.json
EXECUTE=1 scripts/run_pilot.sh SERVED_MODEL WEIGHTS_REVISION runs/refined-pilot \
  --families all --sizes 100,200,300,500,1000,2000 \
  --grid runs/refined-grid.json --seeds 1004-1006
python -m paper_experiments.grids freeze runs/refined-pilot/real/RUN_HASH \
  --output runs/frozen-grid.json
```

`refine` produces pilot candidates only. `freeze` requires completed pilot
records and resolved boundaries. For genuinely unresolved/continuous scenarios
such as S3/S4, `--allow-censored` explicitly records that decision; it never
invents a midpoint. A failure at α=0 calls for inspecting the clean market,
not interpreting an attack threshold. Refining/fixing the system requires new
pilots. Freeze only after policy/horizon settings are final. Main seeds must be
disjoint from the pilot seed identities.

```bash
EXECUTE=1 scripts/run_full_llm_paper.sh SERVED_MODEL WEIGHTS_REVISION \
  runs/frozen-grid.json runs/main --families all --seeds 1-12
python -m paper_experiments.analysis runs/main/real/RUN_HASH \
  --output runs/main-tables --bootstrap-draws 5000
```

Each family can run alone (`--families p05`, `--families p01 p09`, or aliases
`main`, `appendix`, `llm_controls`). Give each differing selection a new
manifest/output path. For cross-backbone P07, repeat against each pinned served
model with the **same frozen P07 grids** and seeds; then pass all run directories
to the analysis command. The release supplies a protocol, not model results.

## Scaling and restart behavior

1000 agents × 30 rounds gives 30,000 model decisions per episode; 2000 gives
60,000. Agents share model weights and keep independent observations/memories.
Within a round, requests are queued concurrently against the shared endpoint,
then all outputs are applied after the barrier. `CONCURRENCY=32` limits in-flight
requests independently of agent count. Tune it from pilot throughput and KV
cache capacity; increasing it does not alter the decision-round schedule.

`--num-shards M --shard-index I` splits whole episodes by stable job ID. Use
distinct shard indices with one shared manifest. The scripts read `NUM_SHARDS`
and `SHARD_INDEX`. Several workers against one GPU server compete for the same
capacity, so benchmark that choice. Each worker must connect to the configured
model/revision. Endpoint identity is included in provenance. Serving a different
model under the same name is not verified automatically; pin and record the
server launch/version/weights configuration.

Completed episodes have atomic JSON records, hashes of config/code/backend and
compressed replay traces. An interrupted episode reruns in full; no partial
episode is counted complete. Failed requests never silently invoke a rule
policy. Resume validates all trace hashes as well as the result checksum.
Changing source, prompts, model settings, grid, horizon, or seed creates a new
identity. A stale `.lock` left by a terminated process must be removed only
after confirming no worker still owns that episode. No result-directory merge
is inferred from filenames. `mock/` and `real/` are separate trees, and analysis
requires `--allow-mock` to inspect mock output.

## Tables and interpretation

Analysis emits episode/condition means, target and realized α midpoints,
harmful counts, 10–90% widths, logistic sensitivity, paired seed bootstrap
(all requested sizes versus each draw's resolved sizes), omitted-size fits,
component/threshold sensitivity, fixed-K response fits on full/subcritical/
zero-failure subsets, per-K size trends, held-out response predictions and
constant/power-law comparisons, and model-call/token audits. The analysis
report records missing cells and unavailable diagnostics. Run it on complete
main manifests for final claims. Mock files are labeled pipeline QA.

The response-surface analysis predicts where a clean-subtracted continuous
score reaches an increment of one. That is not automatically the p=.5 collapse
boundary. Its uncalibrated held-out errors must be reported rather than being
renamed an independent theory validation. Exact old QRE probabilities and
entropy identities do not exist for unconstrained LLM policies; unavailable
quantities remain null. Report explicit model behavior and held-out evidence.
